# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-09-15

### Added
- Prose mode for markdown, rST, text and mail buffers: soft wrap, spellcheck and autocorrect the moment the file opens. `\ss` toggles spelling, `\sa` toggles autocorrect.
- Zen writing mode on `\z` — Goyo with Limelight dimming everything but the current paragraph — in both Vim and Neovim.
- Obsidian vault support through `lervag/wiki.vim`, on `\k`. It activates only for files that sit inside a `.obsidian/` vault, so plain markdown stays plain markdown; `$OBSIDIAN_VAULT` is the per-machine fallback. Needs Vim 9.1+ or Neovim 0.10+.
- scripts/install.sh: one-command bootstrap for a freshly cloned machine — symlinks (~/.config/nvim, ~/.vim, ~/.vimrc), the nvimdata/ data dir, and plugins, in three modes: light (minimal plugin set, no venv/fonts, for remote boxes), normal (full plugin set + Python venv + a Nerd Font, no sudo), and heavy (normal, plus vim/neovim/ripgrep/fd/ctags/pandoc via Homebrew or the system package manager, the only mode that uses sudo). Windows is supported via WSL2, treated as Linux.
- Explicit writing-mode commands: :WriteOn/:WriteOff toggle soft-wrap prose formatting (vim-pencil), :SpellOn/:SpellOff toggle spell-check independently of autocorrect, :AutoCorrectOn/:AutoCorrectOff toggle vim-litecorrect, :ZenOn/:ZenOff idempotently enter/exit Goyo+Limelight. Each has a bare alias (:Write, :Spell, :AutoCorrect, :Zen) equivalent to its On form.
- auto-link ~/.local/share/nvim to gitignored nvimdata/ on every machine (4140ad5).
- add scripts/install.sh — one-command bootstrap in light/normal/heavy modes (2af376f).
- add explicit :WriteOn/:SpellOn/:AutoCorrectOn/:ZenOn commands (5a6f6ea).

### Changed
- vim-pencil is declared as `preservim/vim-pencil`; `reedes/*` only redirects.

### Removed
- vimwiki, vimoutliner, spellwarn.nvim, obsidian.nvim, twilight.nvim and zen-mode.nvim. The note and focus stacks now have one dual-editor answer each.

### Fixed
- restore deny-list Write guards, gate git merge, correct main->master (640becb).
- Markdown files open as `filetype=markdown` again. vimwiki was claiming every markdown buffer anywhere on disk, which starved every `FileType markdown` autocmd and meant vim-markdown had never loaded.
- check.sh no longer drops an editor guard when plugins.vim contains a conditional it does not recognise.
- Neovim's data directory (stdpath('data')) no longer aliases the repo checkout: nvim-treesitter was littering tree-sitter-*.tar.gz into the repo root on every startup and never actually finishing parser installs. `make init` now runs scripts/link-data-dir.sh, which points ~/.local/share/nvim at a gitignored nvimdata/ inside the checkout, and prefer_git is set before nvim-treesitter's install kicks off so future installs use git clone, not tarball download.
- set prefer_git before configs.setup() kicks off installs (c2ba329).

## [0.2.0] - 2026-09-07

### Added
- add: Claude Code integration — SessionStart digest hook, permission allow/deny lists, /end /ctx /release skills, path-scoped plugin rules; skills now live in .claude/skills (CLAUDE/skills symlinked) (c04b4bc)

### Changed
- Replace archived/orphaned plugins with maintained alternatives: syntastic -> dense-analysis/ale (dual editor), vim-scripts/taglist.vim -> preservim/tagbar, YouCompleteMe -> yegappan/lsp (native Vim9 LSP), MikeDacre/vim-go fork -> upstream fatih/vim-go, plasticboy/vim-markdown -> preservim/vim-markdown, bling/vim-airline -> vim-airline/vim-airline.
- consolidate toward maintained, dual-editor plugins (1064207).
- Resolve the Neovim-only plugin audit backlog: drop nui.nvim, nvim-treesitter-refactor, jupytext.nvim, firenvim, leap.nvim, split-term.vim, and nvim-mdlink (unused/superseded); consolidate the three code-runner plugins (sniprun, code_runner.nvim, iron.nvim) down to iron.nvim; drop telescope.nvim + plenary.nvim now that fzf.vim is the sole dual finder; consolidate linting onto ALE for both editors, dropping neomake.
- Correct the premise: Vim 9 is primary, Neovim secondary; resolve ONI and vim-go questions (225b569)
- Record vim-project-config subrepo and nyaovim archive; harden check.sh for compatible mode (f4b036c)
- docs: merge duplicate changelog sections; resolve ONI todo; add E216 and skill-invocation todos (def2dc3)

### Removed
- Drop orphaned, redundant, or non-plugin entries from plugins.vim: vim-misc, nvim-tree.lua (nerdtree is now the single dual file-tree answer), vim-easy-align, vim-project (and its dead config block in init.vim), vim-jsbeautify, html5.vim, jacinto.vim, riv.vim, tmux-plugins/vim-tmux, nerdtree-devicons-syntax, vim-nerdfont, vim-glyph-palette, and the fd/ripgrep Plug lines (not vim plugins — now checked by check.local.sh instead).

### Fixed
- Remove the system() shell-out at startup for g:vim_minimal, the duplicate nvim-treesitter Plug declaration, and the unguarded spellwarn.nvim on plain Vim; resolve the E216 and E488 startup hazards.
- pin nvim-treesitter to master, add plugged/ parity check (b4d66f8).
- Set g:python3_host_prog to a dedicated .venv (created by 'make init') instead of leaving Neovim to guess among system/pyenv/anaconda python3 installs; fixes UltiSnips' 'Python 3 is not available' warning by giving the python3 provider a stable interpreter with pynvim installed.
- Drop 'latex' from nvim-treesitter's ensure_installed — it can't compile without the tree-sitter CLI (not installed) and was erroring on every nvim startup.
- stop nvim-treesitter erroring on latex every startup (9877b19).
- fix: honest check.sh gates (no silent!, nvim exit code, git-based doc staleness), changelog section merge, https submodule url; add mcp-fix.sh, cfg.sh, lib.sh, todo.py from the kit; session.sh ctx/refs/end flow; jq no longer required (3595bd2)

## [0.1.0] - 2026-09-03

### Added

- Project scaffold: `CLAUDE/` rules and facts, `scripts/` session tooling,
  `ROADMAP.md`, `TODO.txt`, this changelog
- `PLUGINS.md` — standing audit of all 84 plugin declarations, with dual-editor
  status and a prioritised backlog
- `doc/mikevim.txt`, generated from `README.md` by panvimdoc, so `:help mikevim`
  is the keymap cheatsheet in both Vim 9 and Neovim
- `deps/panvimdoc` submodule pinned at v4.0.1
- `Makefile` with init, doc, test, check and doctor targets

### Changed

- `README.md` rewritten as the cheatsheet source, with real install steps and a
  full mapping table

### Fixed

- Nothing yet. Editor behaviour is deliberately untouched in this release.
